# 繪圖卡點 Reels 剪輯器

放入一段音樂和一段繪圖過程縮時影片，自動抓節拍、分出草稿／線稿／上色／完成，剪成 1080×1920、30fps 的 IG Reels 卡點影片。

**線上使用：** https://cotton-grass-ouo.github.io/reels-editor-release/

- **影片不會上傳。** 所有分析與輸出都在你的瀏覽器裡完成，沒有後端、不呼叫任何 AI 或雲端服務。
- 整個工具就是一個 `index.html`，也可以下載後直接雙擊開檔、離線使用（字型會改用系統字型）。

## 使用方式

1. **音樂**：選擇有音樂的影片或音檔（IG 螢幕錄影 mp4、mp3、m4a 都可以，只取音軌）。會自動剪掉頭尾靜音、抓 BPM 與第一個重拍。
2. **繪圖過程影片**：選擇繪圖縮時影片。會自動分出四個階段，可以拖曳影格條上的彩色標記微調。
3. **樣式**：選擇風格預設，並決定要不要快閃、特寫、階段文字。
   - **卡點快剪**：每個段落開頭有縮放衝擊，適合一般卡點。
   - **繪師揭曉**：開場和結尾用滑桿對比草稿與成品，IG 自動重播時看起來無縫。
   - **柔和氛圍**：每個切點溶接、鏡頭緩慢推近，適合抒情歌。
4. 按「▶ 預覽」確認效果，再按「輸出影片」→「下載影片」。

所有自動偵測的結果（節拍、階段、特寫位置、快閃畫面）都可以手動調整，也可以一鍵還原。

## 建議的素材

| | 建議 |
| --- | --- |
| 音樂 | mp3／m4a 音檔，或只錄歌曲那一段的螢幕錄影；1～2 分鐘以內、幾十 MB 以內 |
| 繪圖影片格式 | MP4（H.264）。iPhone 的 HEVC／H.265 影片在部分瀏覽器無法讀取 |
| 繪圖影片尺寸 | 1080×1080 或長邊約 1080 即可，不需要 4K |
| 繪圖影片長度 | 15～60 秒的縮時影片（例如繪圖軟體輸出的縮時） |

音樂檔會整個讀進記憶體，檔案太大（例如 1 GB 的螢幕錄影）可能讓頁面變慢或當掉，手機尤其明顯。好幾 GB 的原始繪圖錄影，請先用繪圖軟體輸出成縮時影片再放進來。

## 瀏覽器支援

| 瀏覽器 | 輸出方式 |
| --- | --- |
| **Chrome / Edge（電腦版，建議）** | 逐格離線輸出 MP4，通常比影片本身還快，輸出時可以切到別的分頁 |
| Android Chrome | 多半同上；裝置不支援時自動改用即時錄製 |
| Safari / Firefox 等 | 自動改用即時錄製：要等跟影片一樣久，錄製時頁面要保持在畫面上；有些只能錄成 WebM，要先轉檔才能上傳 IG |

輸出規格：1080×1920、30fps、H.264＋AAC 的 MP4，最後 0.6 秒音訊淡出。

## 版權音樂提醒

如果音樂有版權，IG 可能會把上傳影片的聲音靜音。可以上傳後改用 **IG 音樂庫的同一首歌、從同一段開始**，拍點一樣會對上。
